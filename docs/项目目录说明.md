# nanobuddy-agent 目录说明

## 根目录（常用）

| 路径 | 说明 |
|------|------|
| `main.py` | 启动 FastAPI 服务 |
| `desktop.py` | 桌面壳（webview） |
| `cli.py` | 命令行入口 |
| `config.yaml` | 本地配置（已 gitignore，勿提交） |
| `config.example.yaml` | 配置模板 |
| `setup_deploy.bat` / `一键部署.bat` | 新机安装 venv 与依赖 |
| `launch_nanobuddy.bat` / `启动助手.bat` | 后台启动并打开浏览器 |
| `run_server.bat` / `运行服务.bat` | 带控制台启动（排错） |
| `offline_packages/` | 离线 pip wheel（Git LFS） |
| `scripts/deploy.ps1` | 部署脚本（由 bat 调用） |
| `build.bat` | PyInstaller 打包（产物在 `dist/`，可删后重建） |

## 核心代码

| 路径 | 说明 |
|------|------|
| `core/agent/` | ReAct 核心引擎（`agent_core.py`）、会话记忆（`memory.py`） |
| `core/context/` | 上下文治理：token 压缩（`context_compact.py`）、工具结果裁剪（`context_prune.py`）、会话持久化（`chat_persist.py`）、调试日志（`debug_logs.py`） |
| `core/database/` | SQLite 存取（`db.py`）与数据库密码加解密 |
| `core/document/` | 文档解析（`parser.py`，PDF/Office/文本等） |
| `core/mcp/` | MCP 路径与配置（`mcp_paths.py`）、filesystem 服务配置 |
| `core/models/` | 模型路由与适配器（`models.py`）；API Key 可存设置页数据库并热替换 |
| `core/path_policy/` | 文件路径沙箱（`policy.py`）与团队工作区（`workspace.py`） |
| `core/rag/` | 向量检索：嵌入（`embeddings.py`）、向量库（`vector_store.py`） |
| `core/routes/` | FastAPI 路由：`routes_api.py`（聊天/文件/设置）、`routes_admin.py`、`routes_auth.py`（鉴权）、`routes_security.py` |
| `core/security/` | 鉴权依赖、用户与角色、密钥解析、审计、权限 |
| `core/skills/` | 应用内技能库定义 |
| `core/tools/` | 工具注册（`registry_tools.py`）与各类工具：数据库（`db_tools.py`）、邮件、压缩包、OCR、文件整理等 |
| `core/wechat/` | 企业微信接入（`ilink.py`、`work.py`） |
| `core/`（顶层） | `logger.py` 日志、`presentation.py` PPT 生成、`smart_query.py` 智能问数 |
| `nanobuddy/` | Agent 运行时（基于 [HKUDS/nanobuddy](https://github.com/HKUDS/nanobuddy)，见 `nanobuddy/LICENSE`） |
| `web/` | 前端静态资源（`index.html` + `js/` + `css/`） |
| `prompts/` | 系统提示词模板 |

## 数据与运行时（gitignore，保留即可）

| 路径 | 说明 |
|------|------|
| `data/` | SQLite、向量索引、上传文件等 |
| `sessions/` | 对话会话 JSONL |
| `logs/` | 运行日志、审计 `audit.jsonl` |
| `memory/` | Agent 长期记忆 `MEMORY.md`（可空目录） |
| `knowledge/` | 知识库源文件 |
| `venv/` | Python 虚拟环境 |

## 技能与扩展

|------|------|
| `skills/` | 应用内技能库（`core/skills` 扫描） |

## 开发脚本

| 路径 | 说明 |
|------|------|
| `scripts/dev/` | 飞书/工具等诊断脚本，非生产入口 |
| `scripts/migrate_legacy_data.py` | 一次性迁移：keji.db → nanobuddy.db、向量集合 keji_documents → nanobuddy_documents（幂等） |
| `.env.example` | 环境变量模板（复制为 .env 填写；模型 API Key 在设置页输入，不经过 .env） |
| `scripts/dev/find_silent_except.py` | 扫描 `except Exception: pass` 静默吞错 |
| `scripts/dev/fix_silent_except.py` | 将静默吞错替换为分级日志（一次性修复脚本） |
| `scripts/dev/analyze_deps.py` | 依赖可达性分析（AST import + pip Requires-Dist BFS） |
| `scripts/dev/split_requirements.py` | requirements 拆分为 主/OCR可选/打包 三文件 |
| `scripts/dev/archive/` | 历史一次性诊断脚本（飞书/工具排查，归档备查） |
| `tests/` | pytest 测试（设置优先级、SQL 标识符白名单、provider 热替换、上下文剪枝） |
| `.github/workflows/tests.yml` | CI：push/PR 自动跑 pytest |
| `requirements.txt` | 运行时依赖（主文件，不含 torch） |
| `requirements-ocr.txt` | 可选：OCR 识别（easyocr + torch；无 GPU 用 CPU 版 torch） |
| `requirements-build.txt` | 可选：PyInstaller 打包链 |
| `requirements-dev.txt` | 开发测试依赖（pytest） |
